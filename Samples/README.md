# 🧠 Voice-Enabled Chatbot with Streamlit and Speech Recognition

A simple Python chatbot app that uses **speech recognition** to take voice input and respond intelligently. Built with `speech_recognition`, `Streamlit`, and optionally integrated with NLP libraries.

---

## 📦 Features

- 🎤 Voice input using microphone
- 🗣️ Real-time speech recognition
- 🌐 Web interface using Streamlit
- 🧠 Custom logic / AI responses (extendable)

---

## 🚀 Getting Started

### 🔧 Prerequisites

- Python 3.9 to 3.11 recommended (3.13 can be unstable with some libraries)
- Microphone-enabled device
- Internet connection (for Google API in speech recognition)

---

### 🛠️ Installation

```bash
# Clone the repo or move to your project folder
cd Project_AI

# Create virtual environment
python -m venv .venv

# Activate virtual environment (Windows)
.\.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
